**כתובת האתר:** https://tyuibbbbbbbbbbbb.github.io/
**עמוד העריכה:** https://tyuibbbbbbbbbbbb.github.io/admin.html

## איך משנים טקסט ומוסיפים אפליקציות

### דרך 1: עמוד העריכה (הכי נוח)

1. נכנסים ל-`admin.html`.
2. בפעם הראשונה לוחצים **חיבור ל-GitHub** ויוצרים מפתח גישה לפי ההוראות שבעמוד
   (Fine-grained token, רק לריפו הזה, הרשאת **Contents: Read and write**).
3. עורכים: טקסטים, אפליקציות, פרויקטים, תכונות, שאלות, אפשרויות בטופס ההזמנה.
   הכפתורים ↑ ↓ משנים סדר, ✕ מוחק, ״+ הוספה״ מוסיף. המתג ״מוצג״ מסתיר אזור שלם.
4. לוחצים **שמירה ופרסום** (או Ctrl+S). האתר מתעדכן תוך כדקה.

אפשר גם להעלות תמונות (אייקון לאפליקציה, צילומי מסך של הגרסה). הן נשמרות בתיקייה `images/`.

**אם github.io חסום אצלכם (נטפרי):** לחיצה כפולה על `edit.bat` בתיקיית הריפו במחשב.
הוא מושך את הגרסה האחרונה, מריץ את עמוד העריכה מקומית ופותח אותו בדפדפן. השמירה הולכת ישר ל-GitHub (api.github.com לא חסום).

### דרך 2: עריכה ישירה ב-GitHub

כל התוכן נמצא בקובץ אחד: [`content.json`](content.json). פותחים אותו ב-GitHub, לוחצים על העיפרון, עורכים ושומרים.
צריך לשמור על המבנה (מירכאות, פסיקים וסוגריים), אחרת האתר לא ייטען.

## טופס ההזמנה

בעמוד העריכה, תחת **טופס הזמנה**, ממלאים **מספר וואטסאפ** ו/או **מייל**.
הלקוח ממלא את הטופס, והוא נפתח אצלו כהודעה מוכנה שנשלחת אליכם. בלי שרת ובלי שירות חיצוני.
אם לא ממלאים אף אחד מהם, יש ללקוח רק כפתור ״העתקת ההזמנה״.

## עיצוב בטקסט

- `**מילים**` יוצגו מודגשות.
- ירידת שורה בתיבת טקסט תוצג גם באתר.
