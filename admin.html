חיבור ל-GitHub

כדי לשמור שינויים ולהעלות תמונות, העמוד צריך הרשאת כתיבה לריפו של האתר. ההרשאה נשמרת רק בדפדפן הזה.

איך יוצרים מפתח גישה (פעם אחת)
  1. נכנסים ל-יצירת מפתח חדש ב-GitHub.
  2. נותנים שם (למשל ״עריכת האתר״) ובוחרים תוקף.
  3. תחת Repository access בוחרים Only select repositories ואת ריפו האתר.
  4. תחת Permissions, ב-Contents בוחרים Read and write.
  5. לוחצים Generate token, מעתיקים ומדביקים כאן.

גיבוי

אפשר גם להוריד את קובץ התוכן ולהעלות אותו ידנית לריפו.
